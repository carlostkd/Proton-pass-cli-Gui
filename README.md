# Proton Pass CLI GUI

A graphical interface for the Proton Pass CLI tool built with Python and Tkinter.

## Requirements

- Python 3.x
- Tkinter (usually included with Python)
- `proton-pass-cli` installed and available in PATH

## Installation

1. Ensure `proton-pass-cli` is installed:
   ```bash
   pass-cli --info
   ```

2. Run the GUI:
   ```bash
   python3 pass-cli.py
   ```

## Features

- Command builder for Proton Pass operations
- Vault and item management
- Field discovery and injection
- Session management (login/logout)
- Dark theme UI with customizable output colors
